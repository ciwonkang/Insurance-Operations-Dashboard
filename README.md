# Insurance Operations Dashboard

## Overview

This project develops an insurance operations dashboard using SQL, Excel, and VBA.

The analysis includes:

- Executive KPI summary
- Insurance type analysis
- Monthly claim trend
- Agent performance analysis
- Excel dashboard with VBA refresh automation

## Project Files

- Project4-vba.xlsm – Excel dashboard with VBA automation
- insurance_dashboard.csv – Processed dashboard dataset
- sql – SQL scripts used for data preparation and reporting
